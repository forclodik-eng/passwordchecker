# Password Auditor 🛡️

Android-приложение на Jetpack Compose для глубокого анализа надежности паролей, симуляции различных векторов атак (от словарных до параллельного перебора) и автоматической генерации защищенных вариантов.

## 🚀 Скачать APK

Готовый установочный файл APK можно скачать:
1. Во вкладке **Releases** на GitHub: [Releases](../../releases)
2. Через GitHub Actions артефакты сборки во вкладке **Actions** -> **Build & Release APK**
3. Напрямую в AI Studio через меню настроек проекта (Generate APK / Download).

## ⚙️ Автоматический релиз на GitHub (CI/CD)

В репозиторий добавлен GitHub Actions workflow (`.github/workflows/release.yml`):
- При создании релиза в GitHub (**Releases -> Draft a new release / Publish release**) или отправке тега версии `v*`, экшен автоматически компилирует свежий APK и прикрепляет файл `password-auditor.apk` к релизу.
- Также можно запустить сборку вручную во вкладке **Actions** (`Run workflow`).

### Ручное добавление через GitHub CLI (если нужно):
```bash
# Собрать APK локально:
./gradlew assembleDebug

# Загрузить в существующий релиз:
gh release upload v1.0.0 app/build/outputs/apk/debug/app-debug.apk#password-auditor.apk
```

## 🔑 Функционал приложения

- **Многоуровневый аудит пароля**:
  - Словарная атака (база топ утекших паролей)
  - Выявление клавиатурных дорожек (`qwerty`, `123456`)
  - Поиск дат, годов и PIN-кодов
  - Распознавание L33t-Speak подстановок (`p@ssw0rd`)
  - Масочный анализ корпоративных шаблонов
- **Живой симулятор перебора (Brute Force Engine)**:
  - Визуализация попыток в реальном времени
  - Расчет скорости (попыток/сек) и размера комбинаторного пространства
- **Оценка стойкости до 10.0 и энтропия**:
  - Круговой индикатор оценки
  - Оценка времени взлома на различном оборудовании (онлайн, CPU, GPU RTX 4090, суперкомпьютер)
- **Генератор надежных вариантов**:
  - Усиление введенного пароля
  - Криптографический рандомизатор с настройкой длины и символов
  - Метод мнемонических фраз (Diceware)
